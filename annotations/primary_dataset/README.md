# Recommended dataset split

All of the annotations generated for the IARPA SMART program are provided here as one merged dataset. Anyone using this dataset is encouraged to split the data in any way to accomplish specific research goals or model performance. 

However, for comaprison against results found in our publications, the following breakdown represents the Train/Val/Test split used for the purposes of the IARPA SMART Program. All of the regions listed are found in the Primary Dataset. 

## Validation
- AE_R001
- BR_R002
- KR_R002

## Sequestered Test
- Seq1: CH_R002
- Seq2: KR_R003
- Seq3: NZ_R002
- Seq4: US_R003
- Seq5: BR_R006
- Seq6: US_R012
- Seq7: ZA_R001

## Training Set
All other regions, including those found in the [Secondary Dataset](./secondary_dataset/)
